会陪你玩 Minecraft 的 AI

小遥是一个 Fabric 1.21.11 的 AI 陪玩机器人，以离线账号 xiaoyao 登录你的局域网世界， 跟你聊天、跟着你走。Fabric 模组内置设置界面，可自选提供商、模型、思考强度和 API Key。

下载最新版 查看源码

自选提供商

DeepSeek、OpenAI、OpenRouter、SiliconFlow，或自定义 OpenAI 兼容接口。

模型与思考强度

模型 ID 自由填写，思考强度可选 Off / Low / Medium / High / Max。

Fabric 模组设置

Meteor Client 的 Misc 分类里直接配置并一键启动/停止，无需改代码。

真的会跟随

基于路径寻路跟随你，遇到指令会停下、过来或看向你。

离线账号

以 xiaoyao 离线身份加入；附带 fixlan 模组解决 1.21.11 LAN 正版验证。

独立进程

机器人作为独立玩家登录，不干扰你正在玩的客户端。

需要 Minecraft 1.21.11 + Fabric、Meteor Client、Node.js 20+。

使用

1. 把 xiaoyao-ai-1.0.0.jar 放入 mods；进世界后「对局域网开放」。

2. 打开 Meteor ClickGUI → Misc → Xiaoyao AI，填好 provider、model、thinking、api-key。

3. 打开模块开关，小遥会自动加入并开始聊天、跟随。

API Key 会保存在本地配置里，请不要把配置文件发给别人。

从源码运行内核

git clone https://github.com/Qiuqiu2017/xiaoyao-companion
cd xiaoyao-companion
npm install
node bot.js

也可以设置 XIAOYAO_CONFIG 指向自定义配置文件。
